# DiagKit — Quality Scorecard

Scored under The Elite Software Master Prompt v1.1, §17. Every score names its evidence; a score without evidence would be a Fail. This file is updated in the same change as the work it scores.

**State at v0.1.0: total 85.4/100 — the release bar (total ≥ 85, no dimension below 3, no Fail) is met for the local gate.** Two recorded waivers remain (Performance and Scalability measurements), and Windows runtime behaviour is Partially Verified: CI's real MSVC build is the link gate, and the version-resource path's runtime is Unverified until an on-machine field pass runs it.

## What moves the score

1. On-machine Windows field pass — collect a bundle from a real app install (an exe with a real version resource, logs, a data folder listing) and verify the manifest's version block against the file's Explorer properties page (raises Correctness and closes PARITY's partial row).
2. A recorded collect benchmark + a bundle-at-cap and 5000-entry-listing exercise (closes the Performance waiver and the Scalability follow-up in one pass).
3. Coverage measurement, or recording test-count evidence as the accepted substitute (closes the Test evidence note).
